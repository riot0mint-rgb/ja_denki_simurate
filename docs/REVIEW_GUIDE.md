## 1. まず5分でできる確認

### 1-1. お手元の検針票を1枚入れてみる

「検針票から試算する」→ ご契約プランを選ぶ → 検針月と使用量を入れる。

**現在のご契約側の金額が、検針票の請求額と合っているか**を見てください。
ここが合っていれば、乗り換え後の金額も同じ計算で出しています。

> 合わないときは、検針月（ご使用月ではなく請求の月）と、
> 検針票発行手数料55円が含まれていないことをご確認ください。

## 2. とくにご意見をいただきたい4点

### （1）年額の出し方

「年間の想定おトク額」は、**毎月同じご使用量が12か月続いた場合**の金額です。
12か月ぶんの燃料費調整額をそれぞれ当てて積み上げています（月額の12倍ではありません）。

- この前提の書き方で、お客様に誤解なく説明できますか
- 「年間」を主役にするのは適切ですか。月額のほうが説明しやすいですか

### （2）安くならないときの表示

JAでんきのほうが高くなるお客様がいます（auでんきMプラン、ナイトホリデーの一部）。
その場合は**赤字で「ご負担増」と出し、おすすめのバッジも付けません**。

- この表示で問題ないですか
- 「現在のご契約のご継続をおすすめします」という言い回しは適切ですか

### （3）ガスとでんきのセット割

「あり／なし」を必ず選ぶ形にし、**既定は「なし」**にしています。
セット割に入っていないお客様に割引後の額を見せないためです。

- 現場では「あり」が既定のほうが自然ですか

### （4）入力の多いプランが現場で埋まるか

ファミリータイム・時間帯別電灯・電化Styleは、検針期間や時間帯別の使用量が必要です。

- お客様の前で入力しきれますか
- 「休日の電気の使い方」（同じくらい／多い／とても多い）は聞き取れますか

## 3. お気づきの点の伝え方

金額の食い違いは、次の5点をお知らせください。原因を追えます。

1. プラン名
2. 検針月
3. 入力した値（使用量・契約容量・時間帯ごとの内訳）
4. 画面に出た金額
5. 正しい金額（検針票または試算表の値）

画面の「計算の内訳を表示」を開くと計算式と単価の出典が出ます。
スクリーンショットに含めていただけると確認が速くなります。
