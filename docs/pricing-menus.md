### 要修正 2 件

**① 中電スマートコース：最低料金 622.91 → 669.92（+47.01円）**

622.91 円は 2023年6月〜2024年3月 に適用されていた **JAでんき従量電灯S の旧最低料金** と同額であり、
2024年4月の託送料金改定（中国エリアの最低料金が一律 +47.01 円）が未反映。
段階単価（32.01/39.43/41.55）は現行値のため、**同一シート内で新旧単価が混在**している。

**② ドコモでんき Basic：712.67 / 32.83 / 39.51 / 41.63 → 759.68 / 32.75 / 39.43 / 41.55**

シート全体が 2024年4月改定前の単価。最低料金の差は同じく +47.01 円。
現行のドコモでんき Basic は中国電力 従量電灯A と完全同額のため、
改定後は「中電従A」シートと同一の計算になる。

いずれも **現在の電気料金を過小に見積もる** 方向の誤りであり、
検針票の金額から推定使用量を逆算する本シミュレータでは推定使用量が過大になり、
結果として **JAでんきの削減額が実態とずれる**。
