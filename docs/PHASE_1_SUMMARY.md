## 🔧 技術決定事項（フェーズ1で確定）

### 言語・フレームワーク

- **共通ライブラリ**: TypeScript
- **金額計算**: Decimal.js（10進固定小数）
- **Web UI**: React / Vue / Svelte（フェーズ4で詳細決定）
- **テスト**: Jest + TypeScript
- **ビルド**: Vite
- **デプロイ**: 静的ホスティング（SharePoint / Azure Static Web Apps 等）

### 非機能要件（固定）

| 要件 | 決定内容 | 理由 |
|------|---------|------|
| サーバー | 不要（Phase A） | 個人情報をサーバーに送信しない |
| 金額計算 | Decimal.js | 浮動小数点エラー排除 |
| データ永続化 | なし（デフォルト） | ブラウザメモリのみ |
| HTTPS | 必須 | セキュリティ基準 |
| PWA | 必須 | スマートフォンホーム画面対応 |
| テスト | 100%（calc-core） | 金額計算の信頼性 |
