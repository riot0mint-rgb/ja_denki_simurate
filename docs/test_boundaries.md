## 🔍 相対値から絶対値への変換テスト

### 中国電力 参照値が必要な項目

一度中国電力の公開料金定義書が入手できたら、以下の変換を実施：

```
JAでんき Tier2単価（絶対値）
  = 中国電力 Tier2単価 - 1.39 円/kWh
  
JAでんき Tier3単価（絶対値）
  = 中国電力 Tier3単価 - 2.71 円/kWh
  
JAでんき 基本料金（絶対値）
  = 中国電力 基本料金（同額）
```

### テストデータ（相対値）の検証例

**仮定**: 中国電力 従量電灯A:
- Tier2: 25.00 円/kWh
- Tier3: 27.71 円/kWh

**計算結果（仮定値）**:
- JAでんき Tier2: 25.00 - 1.39 = 23.61 円/kWh ✓
- JAでんき Tier3: 27.71 - 2.71 = 25.00 円/kWh ✓

## 🧪 最小~最大の計算テスト

### テストシナリオ1: 小使用量（従量電灯S推奨）

**条件**: 使用量 50 kWh
```
JAでんき 従量電灯S: 
  基本料金 + (50 × tier1単価)
  = (中国電力基本 - 89.76) + (50 × tier1単価)
```

**期待される削減**: 月数十～百円程度（Q15参照）

---

### テストシナリオ2: 標準使用量（従量電灯A推奨）

**条件**: 使用量 300 kWh
```
JAでんき 従量電灯A:
  基本料金 + (15×tier1) + (105×tier2) + (180×tier3)
  相対値: Tier2で▲1.39円×105 + Tier3で▲2.71円×180
  削減額: (1.39×105) + (2.71×180) = 145.95 + 487.80 = 633.75円/月
```

**期待される削減**: 月600円前後（営業資料の150kWh→400kWh比率から推測）

---

### テストシナリオ3: 大使用量（従量電灯A大削減）

**条件**: 使用量 900 kWh
```
削減額（相対値計算）:
  = (1.39×105) + (2.71×(900-120))
  = 145.95 + (2.71×780)
  = 145.95 + 2,113.80
  = 約 2,260円/月

削減率（営業資料参照）: 3-5%
```

**期待される削減**: 月2,000円前後（営業資料での300kWh⇒900kWhでの年額差の1/12）
