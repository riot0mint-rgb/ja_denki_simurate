## 2. 発見された不整合

### クラス A — シートのハードコードが、同じワークブックのマスタと食い違う

ワークブック単体で証明できる。3 シートとも表示用内訳のラベルが `従量電灯A` のままで、
**`中電従A` シートを複製したあと内訳ブロックを更新し忘れた**ことがうかがえる。

| シート | ハードコード（`AB23` / `X24` / `X25` / `X26`） | `基本項目` マスタ | 差 |
|---|---|---|---|
| `中電スマート` | **622.91** / 32.01 / 39.43 / 41.55 | **669.92** / 32.01 / 39.43 / 41.55 | 最低料金 **+47.01** |
| `auでんきMプラン` | 759.68 / 32.75 / 39.43 / 41.55 | 759.67 / 32.74 / 39.42 / 41.54 | 各 **1 銭** |
| `ソフバ　くらし` | 759.68 / **32.75 / 39.43 / 41.55** | 759.68 / **32.42 / 38.24 / 39.47** | 第2段階 **▲1.19**／第3段階 **▲2.08** |

**対応表も同じ誤った単価から作られている**ため、表示だけでなく使用量の逆算にも効く。

- `中電スマート` の `S6`（0kWh の従量料金+燃調費）は **475**。
  622.91 − 147.69 = 475.22 から導かれ、マスタの 669.92 では 522 になるはず。
- `ソフバ　くらし` の対応表は `中電従A`・`ソフバ　おうち` と**完全に同一**（673〜41,908 円）。
  くらしでんき の単価では別の値になるはずで、事実上 従量電灯A として計算されている。

**影響が最も大きいのは `ソフバ　くらし`。** くらしでんき は 従量電灯A より第2・第3段階が
大幅に安いため、現在の電気料金を過大に見積もり、JAでんき の削減額を過大に見せる。
他の 2 件は逆に現在の料金を過小に見積もる。

## 3. 燃料費調整額は事業者ごとに別テーブル

`基本項目` は燃調を **4 系統**持っている。最低料金分（15kWh まで）と超過分（1kWh あたり）が
それぞれ年 × 月のグリッドで管理されている。

| 系統 | 適用先 | 2026年5月（15kWhまで / 超過分） |
|---|---|---|
| 規制料金 | 中国電力 従量電灯A | −147.69 / −9.83 |
| 自由料金 | 中電スマート・シンプル、JAでんき | −147.69 / −9.83 |
| auでんき | auでんき Mプラン | **−147.67 / −9.85** |
| ソフトバンク | おうちでんき・くらしでんき | −147.69 / −9.83 |

auでんき だけ単価が異なる（シート上の注記: 「AUでんき燃調費 15kWまで＝−0.01、それ以降＝+0.01」）。
月によってはソフトバンク系も規制料金と乖離する（例: 2025年8月 −183.89 vs −177.90）。

**単価マスタを実装に移すときは、この 4 系統を保持すること。**

## 5. 計算モデルの注意点

対応表の再エネ賦課金列（`T`）は、使用量 0kWh でも **62 円**（＝ 4.18 × 15kWh の切り捨て）を計上する。
最低料金が最初の 15kWh をカバーするため、賦課金も 15kWh 分が最低保証になる。

```
再エネ賦課金 = floor(賦課金単価 × max(使用量, 15))
```

また、**対応表（`Q` 列）と表示用内訳（`AB35`）は同じ使用量でも 1 円程度ずれる。**
310kWh・中電従A で対応表 9,957 円、内訳 9,958 円。丸めの適用箇所が両者で異なるため。
Excel 自身が「あくまでも簡易的な試算」と断っている範囲の誤差だが、
Phase 2 で再現するときは**どちらを正とするか決める必要がある**。
