## この文書は何か

**決まった数字を入れて、決まった数字が出るかを確かめるだけ**のシートです。
判断が要らないので、誰がやっても同じ結果になります。

| | この文書 | docs/ACCEPTANCE_TEST.md |
|---|---|---|
| 目的 | いま動くかを手早く確かめる | 本番に出してよいかを決める |
| 所要 | 15〜20分 | 機械5分＋人30分 |
| 検針票 | 要らない | **実物が要る（最重要項目）** |
| やる人 | 誰でも | 開発担当＋業務担当 |

⚠️ **ここが全部○でも、本番に出してよいことにはなりません。**
実際の検針票との突合（ACCEPTANCE_TEST.md 2-1）は、これとは別に必要です。

### 3-2. 試算の数字が、そのまま台本に入るか

2-2 で 600kWh の試算をした状態から始めます（していなければ先に 2-2 を）。

1. 「試算」→「検針票から試算する」→ **従量電灯A / 600kWh**
2. 結果画面の **「商談ナビにもどる」**

| 確かめること | 期待 | ○/× |
|---|---|---|
| **戻った先が「説明」の段階になっている** | なっている（試算の画面ではない） | |
| 画面の上の帯 | **試算：JAでんき 従量電灯A で年間 13,428円 おトク** | |
| 「今日の試算を、そのまま読む」が出る | 出る | |
| その台本に年間の料金が2つ入っている | **231,624円** と **218,196円** | |
| 差額が入っている | **13,428円** | |
| 月額が入っている | **1,119円** | |
| 「なぜ安くなるのですか」と聞かれたら…を開ける | 開ける | |
| 「試算」に戻ると、いまの試算の要点が出る | 出る（600 kWh・2026年8月） | |

> **これが無いと台本になりません。** 「1年でこちら」と書いてあっても、いくらかは
> 画面を見比べないと分からず、その数秒で目線が落ちて話が切れます。
>
> 帯の金額は、**どの段階にいても見えます**（聞く・不安・手続き、どこでも）。

さらに、「不安」で **「解約金がかかるのでは」** を開いてください。

| 確かめること | 期待 | ○/× |
|---|---|---|
| 「今日の試算から言えること」が出る | 出る | |
| その中身 | 「仮に解約金が **13,428円** を下回るのでしたら、1年で取り返せる…」 | |
| 解約金があると**決めつけていない** | 「仮に」と言っている／確認をお願いしている | |

> 素人は「解約金はかからないと思います」と答えてしまいます。それは調べていない
> 推測で、外れたときに取り返しがつきません。**分かっているのは差額のほうだけ**なので、
> 分かっている側から話す形にしています。

そして **「「なぜ安くなるのですか」と聞かれたら」** を開いてください。

| 確かめること | 期待 | ○/× |
|---|---|---|
| ① 変わらないもの | 「電気そのものは、いまと何も変わりません」「同じ中国電力ネットワーク」 | |
| ② 変わるもの | 「2016年に電気の小売りが自由化されまして…」 | |
| ③ なぜ安いのか | 「料金表そのものが中国電力より安く作られています」 | |
| ④ お客様の場合 | 「たくさんお使いになる月ほど、差は大きくなります」＋内訳 | |
| **単価の話から入っていない**（①が先） | ①→②→③→④の順 | |
| 確かめていない理由を足さないよう戒めている | 「JAは営利目的ではないので安いんです」など | |

> **単価の内訳は「答え」ではありません。** 「第3段階の単価が2.71円安いからです」は
> 正確ですが、お客様が聞きたいのはそこではありません。この質問はたいてい
> 「電気の質が落ちるのでは」「裏があるのでは」から出ています。
>
> なお **JAでんきがなぜその価格にできるのか（事業の事情）は、あえて書いていません。**
> 出典を持っていないためです。推測で補うと、後で違っていたときに信用を失います。

「安いのには裏があるのでは」「答えられない質問が出たら」も開いてください。

| 確かめること | 期待 | ○/× |
|---|---|---|
| 「裏があるのでは」の答え | 「ご自分で確かめられる、というのがいちばんの答え」 | |
| 答えられない質問の一覧が出る | 4件（事業の事情・解約金・来年以降・停電の頻度） | |

### 4-2. サンプルを貼って数える

| 確かめること | 期待 | ○/× |

>   **前向きな反論であることが数字で確かめられます**
> - E が「—」なのは、5件に満たない区分では割合を出さないためです
